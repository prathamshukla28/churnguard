# Architecture Decision Records

Each ADR captures one significant decision — its context, the choice, and the
consequences — so the *why* behind the code survives after the discussion is
forgotten. Format follows Michael Nygard's template. ADRs are immutable once
accepted; a reversal is a new ADR that supersedes the old one.
